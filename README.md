# Android_Apps

A collection of basic Android applications built to practice and demonstrate Object-Oriented Programming (OOP) concepts using Java.

## Apps Included

- AdapterList: Example of using adapters in Android.
- BroadCast: Demonstrates broadcast receivers.
- DataBindingApp: Shows data binding usage.
- ExplicitIntent: Explicit intent usage demo.
- Fragments: Basic fragment usage.
- FragmentsApp: Advanced fragment navigation.
- FrenchApp: Simple language learning tool.
- HelloWorld: Your first Android app.
- MarketApp: Simulated marketplace demo.
- MyCalculatorApplication: Basic calculator.
- ...and more!

## Getting Started

1. Clone the repository:
    
    git clone https://github.com/Leela0o5/Android_Apps.git
    
2. Open the desired project folder in Android Studio.
3. Build and run on an emulator or device.

## Prerequisites

- Android Studio (latest recommended)
- Java JDK 8 or above
